### 소품 효과

| 파일 | 역할 |
| --- | --- |
| `light_effect.tscn` | 조명을 켰을 때 사람이 모이는 지점 (1600, 1120)에 나타나는 효과 |

- 라이브러리에서 가져온 효과를 씬 파일 하나로 저장합니다. 루트는 `Node2D` 계열을 권장합니다.
- 씬이 생성될 때 스스로 재생되어야 합니다(애니메이션 자동 재생, 파티클 `emitting` 켜기).
- 12초 동안 유지된 뒤 코드가 지웁니다. 짧은 효과라면 반복 재생으로 설정합니다.

### 사운드와 폰트

사운드는 `audio/`(ogg, mp3, wav 중 아무 형식, 같은 이름이면 이 순서로 고름), 폰트는 `assets/fonts/` 폴더에 넣습니다. 폰트는 `BadaBoomBB.ttf`(제목), `MightMakesRightBB.ttf`(나머지 전부)만 씁니다.

| 파일 | 역할 |
| --- | --- |
| `audio/music.wav` | 배경 음악 (반복) |
| `audio/crowd.wav` | 군중 웅성임 (반복). `crowd.m4a`는 Godot이 못 읽어 모노 wav로 변환. 평소 -6dB(`CROWD_VOLUME_DB`) |
| `audio/heartbeat.wav` | 심장박동 (반복). 휴대폰 화면에서만 들림. 사람이 가까울수록 커지고 빨라짐 (`HEART_VOLUME_DB_RANGE` -24 → +8dB) |
| `audio/chatter.ogg` | NPC 수다 (반복, 거리 감쇠) |
| `audio/footstep.wav` | NPC 발소리 (반복, 걸을 때만). 가까울수록 크게 (`FOOTSTEP_VOLUME_DB` +10dB, `FOOTSTEP_ATTENUATION` 2.5, 700px 밖은 안 들림) |
| `audio/alert.wav` | 사람이 경계 반경에 들어오면 재생, 벗어나면 멈춤 |
| `audio/vibrate.wav` | DM 도착, 홈 화면 알림. 첫 진동 0.5초(`VIBRATE_CLIP_SEC`)만 재생 |
| `audio/game_over.wav` | 게임 오버 |
| `audio/music_slow.mp3` | 슬로우 댄스 타임 음악 (반복). 배경 음악보다 8dB 크게, 그동안 군중 소리는 24dB 더 줄임 |
| `audio/take_l.mp3` | LLL 입력 시 그 레벨 동안 배경 음악으로 반복. +3dB(`EASTER_MUSIC_VOLUME_DB`), 휴대폰을 켜면 8dB 줄어듦. 다시 입력하면 처음부터 |
| `audio/baji.wav` | BAJI 입력 시 그 레벨 동안 배경 음악으로 반복. 음량 규칙은 take_l과 같음 |
| `audio/horror.ogg` | 히든 엔딩 공포 효과음 |
| `audio/knockback.wav` | 길막으로 밀려날 때 |
| `audio/reaction_positive.mp3` | 왼쪽 클릭 긍정 반응 (1.7초. 같은 이름의 wav보다 짧아 이쪽을 씀) |
| `audio/reaction_negative.wav` | 오른쪽 클릭 부정 반응 |
| `audio/menu_music.ogg` | 메뉴 음악 (반복) |
| `audio/game_over2.wav` | GAME OVER 도장 소리 |
| `audio/send.ogg` | 답장 완료, 레벨 선택 화면에 메시지가 올 때. 한 번에 0.5초(`SEND_CLIP_SEC`)만 재생 |
