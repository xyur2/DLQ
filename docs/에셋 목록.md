# 에셋 목록

이미지와 효과는 모두 `assets/` 폴더 한곳에 넣습니다. 파일 이름이 정확히 같아야 하며, 파일을 넣은 뒤 Godot 에디터를 한 번 열면 자동으로 가져오기가 되어 게임에 반영됩니다.

## 적용된 에셋

| 파일 | 원본 크기 | 쓰는 곳 | 적용 방식 |
| --- | --- | --- | --- |
| `phone.png` | 360×360 | `phone.tscn`의 `PhoneImage` | 3.4배 확대. 투명한 화면 부분 뒤에 흰색 `ScreenBackground`를 깔았음 |
| `phone_hands.png` | 1024×765 | `phone.tscn`의 `Hands` | 1.6배 확대. 손가락이 화면을 가리지 않도록 휴대폰 뒤에 둠 |
| `bubble.png` | 554×554 | `letter_button.tscn` | 파란 말풍선 (314, 170, 218×80)은 누를 수 있는 상태, 회색 말풍선 (23, 244, 216×78)은 누를 수 없는 상태 |
| `loading_bar_back.png` | 640×60 | `phone.tscn`의 `TimerBar` | 400×38로 표시 |
| `loading_bar_fill.png` | 640×60 | `phone.tscn`의 `TimerBar` | 왼쪽부터 잘려 나가며 줄어듦 |
| `dm_icon.png` | 3840×2160 | `hud.tscn`의 `Icon` | 가운데 2160×2160만 잘라 96×96으로 표시 |

전원 버튼은 `phone.png`에 그려진 버튼(본체 오른쪽 옆면) 위에 투명한 `PowerHitbox`(44×71)를 얹었습니다. 그림의 버튼이 작아서 판정은 그보다 조금 넓습니다.

## 필요한 에셋

아래 파일이 없으면 임시 도형으로 표시됩니다. 소리와 효과는 생략됩니다.

### 탑뷰 이미지

| 파일 | 크기(px) | 역할 | 제작 규칙 |
| --- | --- | --- | --- |
| `party_map.png` | 2016×1536 | 파티장 맵 배경 | 바깥 48px는 벽, 안쪽 1920×1440이 걸어 다니는 공간. 충돌은 코드가 처리하므로 그림의 벽 위치를 이 기준에 맞출 것 |
| `player.png` | 256×512 권장 | 주인공 AnimatedSprite2D 시트 | 아래 "캐릭터 시트 규칙" 참고 |
| `npc.png` | 256×512 권장 | 파티 참석자 AnimatedSprite2D 시트. 5명이 같은 시트 사용 | 아래 "캐릭터 시트 규칙" 참고 |
| `prop_speaker.png` | 정사각형 권장 | 스피커 버튼 | 48px로 맞춰 표시. 재사용 대기 중에는 코드가 어둡게 처리 |
| `prop_light.png` | 정사각형 권장 | 조명 스위치 버튼 | 위와 같음 |
| `prop_playlist.png` | 정사각형 권장 | 플레이리스트 버튼 | 위와 같음 |

**캐릭터 시트 규칙**

- 한 줄에 4프레임, 8줄입니다. 프레임 크기는 시트를 4×8로 나눠 계산하므로, 프레임 64×64이면 시트는 256×512입니다.
- 프레임 가운데가 충돌 원(지름 약 38px)의 중심입니다. 재생 속도는 초당 8프레임입니다.

| 줄(위부터) | 애니메이션 | 언제 재생 |
| --- | --- | --- |
| 1 | `idle_down` | 아래를 보고 멈춤 |
| 2 | `idle_up` | 위를 보고 멈춤 |
| 3 | `idle_left` | 왼쪽을 보고 멈춤 |
| 4 | `idle_right` | 오른쪽을 보고 멈춤 |
| 5 | `walk_down` | 아래로 걷기 |
| 6 | `walk_up` | 위로 걷기 |
| 7 | `walk_left` | 왼쪽으로 걷기 |
| 8 | `walk_right` | 오른쪽으로 걷기 |

### 소품 효과

| 파일 | 역할 |
| --- | --- |
| `light_effect.tscn` | 조명을 켰을 때 사람이 모이는 지점 (1600, 1120)에 나타나는 효과 |
| `playlist_effect.tscn` | 플레이리스트를 틀었을 때 무대 (960, 160)에 나타나는 효과 |

- 라이브러리에서 가져온 효과를 씬 파일 하나로 저장합니다. 루트는 `Node2D` 계열을 권장합니다.
- 씬이 생성될 때 스스로 재생되어야 합니다(애니메이션 자동 재생, 파티클 `emitting` 켜기).
- 12초 동안 유지된 뒤 코드가 지웁니다. 짧은 효과라면 반복 재생으로 설정합니다.

### 사운드와 폰트

사운드는 `audio/`, 폰트는 `fonts/` 폴더에 넣습니다.

| 파일 | 역할 |
| --- | --- |
| `audio/music.ogg` | 배경 음악 (반복) |
| `audio/crowd.ogg` | 군중 웅성임 (반복) |
| `audio/heartbeat.ogg` | 심장박동 (반복) |
| `audio/chatter.ogg` | NPC 수다 (반복, 거리 감쇠) |
| `audio/footstep.ogg` | NPC 발소리 (반복, 걸을 때만) |
| `audio/alert.ogg` | 사람이 경계 반경에 들어올 때 |
| `audio/vibrate.ogg` | DM 도착 |
| `audio/game_over.ogg` | 게임 오버 |
| `fonts/NotoSansKR-Regular.ttf` | 한글 폰트. 넣은 뒤 `project.godot`에 `[gui] theme/custom_font` 추가 필요 |
